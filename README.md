# kitchen

A research lens on food — one of Sankha Cooray's research lenses.

Deployed at **[kitchen.sankhacooray.com](https://kitchen.sankhacooray.com)** via GitHub Pages.

## Members

This lens groups the following projects (see `kitchen-sankhacooray-com.code-workspace`):

- **mixlab** — Cocktails as measured systems — ratios, dilution, and balance made explicit.
- **coffeelab** — Brew variables as a controllable surface: dose, ratio, grind, time.
- **safebite** — Food-safety and allergen checks — a client front with an Apps Script backend.
- **umami** — A tasting / recipe playground exploring flavour as something you can compose.
